
# Live provider notes

The app is wired around:
- X API v2 recent post search with Bearer-token authentication.
- Birdeye Solana token overview, token security, token creation info and OHLCV.
- Helius Solana DAS/RPC `getAsset`.

Provider access, pricing, quotas and endpoint availability can change. The UI therefore reports missing/blocked data instead of substituting demo numbers.
